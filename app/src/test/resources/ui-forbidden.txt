# Förbjudna mönster för regel 4 – enda källan.
# Läses av hooken .claude/hooks/regel4-check.mjs och av UiConsistencyTest (#11).
# Format per rad: <regex><TAB><vad som ska användas i stället>
# [feature]   = Kotlin i ett ui-paket under app/src/main utom ui/components, ui/theme, ui/common
#               (även filer direkt under ui/)
# [firestore] = all Kotlin under app/src/main utom data/firestore/
# [expressive] = all Kotlin under app/src/main utom ui/theme/ och ui/components/
# [dispatchers] = all Kotlin under app/src/main utom di/ (skill android:kotlin-coroutines)
# [events]    = all Kotlin under ui/, även ui/components och ui/common (skill android:kotlin-flows)
# Tillåtet i feature-kod: Text (med AppTheme.typography-stil), Icon (appens ikoner i res/drawable),
# Column, Row, Box, Spacer med Spacing, samt allt i ui/components och ui/common.
# Regexarna ska fungera både i JavaScript och Kotlin (ingen lookbehind).
